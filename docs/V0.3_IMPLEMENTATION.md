# MobileScan3D V0.3 — HQ Reconstruction

V0.3 upgrades the V0.2 engineering foundation toward a phone-only reconstruction loop, without ARCore.

## Implemented in this drop

- Camera2 + YUV capture remains fully native Android.
- High-rate IMU remains independent of camera delivery.
- Lightweight visual-inertial state estimator:
  - gyroscope integration for orientation drift tracking
  - image-gradient feature counting
  - frame-to-frame visual novelty estimate
  - coarse image-motion translation proxy
- Keyframe database:
  - quality score
  - sharpness/exposure/features/novelty gating
  - bounded rolling keyframe history
- Next-Best-View guidance:
  - low novelty → move laterally
  - blur → slow down
  - low exposure → seek even lighting
  - low texture → move closer / change side
- Gaussian ingestion now uses the estimated motion proxy instead of a completely fixed shell.
- TSDF remains part of the reconstruction state.
- Vulkan capability detection remains enabled.

## Important truth about V0.3

This is **not yet a production-grade photogrammetry/SLAM implementation**. The visual tracker is intentionally self-contained and dependency-light, but its pose is still a coarse estimator. Depth is still represented by a conservative placeholder until a real on-device neural depth + multi-view stereo backend is integrated.

Therefore the V0.3 APK/project should be treated as a **reconstruction-engineering milestone**, not as a finished scanner.

## V0.4 target

1. Bundle a real on-device monocular depth model (NNAPI/Vulkan-capable backend).
2. Implement multi-view stereo depth from keyframe pairs/triples.
3. Replace coarse motion proxy with feature matching + geometric pose estimation + local bundle adjustment.
4. GPU depth-to-XYZ and confidence fusion.
5. Real Vulkan Gaussian projection/tile binning/sorting/rasterization.
6. Sparse voxel-hashed TSDF with adaptive voxel size.
7. Region confidence map and scan-coverage heatmap.
8. Detail-pass capture at 20–40 cm and multi-scale Gaussian layers.
9. Export path for PLY/OBJ/GLB after geometry is sufficiently stable.
