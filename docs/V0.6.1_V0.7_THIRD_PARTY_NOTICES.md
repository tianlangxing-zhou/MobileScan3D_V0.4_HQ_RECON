# Third-party note

V0.6.1/V0.7 does not bundle a new third-party SLAM library.

It uses dependencies already present in the MobileScan3D project:

- OpenCV: ORB, Hamming BFMatcher, solvePnPRansac / solvePnP
- VINS-Mono estimator / feature tracker already integrated in the project

The optional xatlas integration remains part of the previous V0.6 patch.

V0.7 does not copy the upstream ROS pose_graph implementation or a BRIEF
vocabulary into this patch. It implements a compact mobile relocalization layer
from persisted VINS-world 3D landmarks + ORB descriptors.
