# MobileScan3D V0.4 — HQ Reconstruction

## 本版本真正新增的部分

1. **外部深度注入通道**
   - `nativeOnDepthMap()` 接收端侧 AI / MVS 生成的米制深度。
   - 深度进入统一 DepthFusion，不再要求 ARCore。
2. **稀疏 TSDF 哈希体素**
   - 真实创建 voxel hash。
   - 对有效深度进行空间融合。
   - 支持导出 PLY 点云。
3. **深度→几何融合链路**
   - Camera intrinsics + pose + depth → XYZ → TSDF。
   - External depth 存在时停止伪深度 fallback。
4. **AI 后端接口保持独立**
   - 下一步可以接 LiteRT / GPU / NPU depth model。
   - 不把不存在的模型权重伪装成“AI 已完成”。
5. **Vulkan 继续作为 GPU 主路径**
   - 后续应把 depth-to-XYZ、voxel integration、Gaussian projection/binning/rasterization 迁移到 Vulkan compute。

## 当前仍然不是最终版本

- VIO 仍然是轻量视觉惯性估计，不是完整 ORB-SLAM / VINS / BA。
- 当前包没有捆绑深度神经网络权重。
- MVS 的 dense stereo 尚未成为默认深度源。
- TSDF 已是真实稀疏 voxel 数据结构，但仍需要 GPU 化和 marching cubes / dual contouring 网格提取。
- Gaussian 当前仍主要用于增量表示，Vulkan rasterizer 尚未完成完整生产级排序与 splat blending。

## 下一阶段 V0.5

- LiteRT 2.x `CompiledModel` 接入端侧 depth model。
- Keyframe feature track + geometric MVS。
- Pose graph + local bundle adjustment。
- GPU depth→XYZ + voxel hashing。
- Vulkan Gaussian tile binning + depth ordering + alpha compositing。
- TSDF → mesh extraction。
- Next Best View 基于 coverage/confidence map，而不是简单 novelty。

## Vulkan 依据

Android 官方当前文档明确 Vulkan 是 Android 的主要低层图形 API；Vulkan 1.3 的平台支持从 Android 13 / API 33 起，但最终能力仍取决于设备驱动，因此运行时必须检查实际 `VkPhysicalDeviceProperties`。同时官方建议 NDK 25+ 以获得 Vulkan 1.3 headers，并将 GLSL/HLSL 离线编译为 SPIR-V。
