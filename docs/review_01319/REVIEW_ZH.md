# 连续重建代码审查与修复记录

日期：2026-09-28。基线：`49f5e9a5a8bb8bf46bb55513e9bde0e052c5f9f7`。
目标：手机移动到另一角度时，继续在同一世界坐标系内累计静止物体的点云与网格。
以下是源码中确认存在的缺陷及修复，不把源码分析等同于已经复现用户设备上的全部现象。

## 1. 实际处理链

`MainActivity.processImage` 取得 Camera2 YUV 与 SENSOR_TIMESTAMP，调用 native VINS/目标追踪；`scheduleDepth` 在独立线程推理，再把原始帧时间戳传回 `nativeOnDepthMapImpl`。
原生层把深度反投影为相机点，以相机到世界的 R、t 转为世界点，写入 SurfelEngine 和 TsdfEngine。MeshEngine 从 TSDF 的零交叉面提取网格。PointCloudRenderer 用当前预览对应的世界到相机变换显示累计点和网格。

正确关系是：`Pw = Rwc(t) * Pc(t) + twc(t)`。RGB、深度、目标框和 R/t 都必须描述同一次拍摄；已有 Pw 不能因相机移动而重新居中。

## 2. 确认的问题

| 位置 | 原行为 | 影响与本次修改 |
| --- | --- | --- |
| `vins_bridge.cpp::vinsInputImage` 与 `native_engine.cpp::nativeOnCameraFrameImpl` | VINS 特征发布约 10Hz，未更新求解器的相机帧仍调用 `vinsGetPose`，再把返回的旧位姿标成当前帧时间戳 | 移动时深度与位姿错配。本次缓存最新优化状态，通过同一 IMU 队列只读传播到当前曝光时间；无有效 IMU 支持时不生成快照 |
| VINS 位姿接口 | 普通接口返回 IMU/body 位姿；持久地图接口另有相机外参变换 | 当前 Kotlin 已把 IMU 重映射到相机方向，且外参为单位矩阵/零平移，所以不能把单位外参认定为本次直接根因。本次新接口显式计算 Rwc=Rwi*Ric、twc=Pwi+Rwi*tic，统一语义 |
| `nativeOnDepthMapImpl` | 异步深度用完成推理时的最新目标框 | 手机转动后，旧图的深度被较新画面的框裁剪。FrameSnap 现保存源帧 TargetTrackInfo 与目标代号；换目标前的在途帧不再进入新目标模型 |
| Fusion epoch | 极端拟合差持续 30 帧可调用清几何函数，重开标定 epoch | 自动抹掉旧表面，外观像重新扫描。本次移除自动清空路径，保持原映射、原几何，暂停直到证据支持恢复 |
| 30 秒标定超时 | 自动绕过标定，把 raw 输出灌入几何，甚至绕过逆深度检查 | 相对深度/逆深度不是相机米制 Z，不能靠超时变成有效尺度。本次删除自动旁路；等待真实标定 |
| V0.13.18 场景 surfel | TSDF 暂停后，仍用 zEpoch 写入场景点云 | 点云和模型采用不同准入条件，继续积累被融合门控拒绝的表面。本次恢复共同门控，保留中心加权采样 |
| 时序深度一致性 | 大幅不一致时仅降权，仍写入另一层表面 | 重叠区一致率低于现有 0.35 门限时拒绝 dense 写入，保留上次有效参考。重叠样本不足时沿用现有中性处理，不把新视角一概判错 |
| 默认 LIVE 图层 | 累计模型叠加每帧替换的相机空间绿色调试点 | 即使没有有效累计模型，也容易误认“这一角度又建了一份”。LIVE 现只显示累计世界点云与网格，调试图层仍可显式选择 |
| AR 预览位姿查询 | 容许 500ms 旧位姿，并回退到最新位姿 | 旋转时会显示到错误角度。本次恢复 80ms 限制，区间内平移插值/四元数 slerp；无可用位姿时隐藏 AR 叠层，不删除模型 |
| Estimator 内部失败重启 | 新世界坐标可能继续写进旧几何 | 检测 NON_LINEAR → INITIAL 重启后锁定世界不连续状态；保留旧模型，拒绝新世界融合，提示导出后重开扫描 |

## 3. 实现边界

新增 `vins/pose_prediction.h`：从最新优化状态的姿态、位置、速度、IMU 偏置、重力和末端 IMU 观测出发，使用中值积分与末段插值。只读 IMU 队列，不推进求解器、不抢走下一次视觉更新需要的数据。传播上限 150ms，IMU 样本间隔上限 25ms；缺失末端样本则拒绝，不用旧位姿冒充当前帧。

FrameSnap 保留 60 帧，运行中的深度任务仍单独 pin 源帧。深度的最近快照容差从 80ms 收紧到 12ms；通常单目推理使用完全相同的时间戳。目标框取同一个快照。深度处理前检查世界连续性和目标代号。

现有短暂跟踪失败可以在同一世界坐标恢复后继续。真正的 VINS 世界重启不等于“同一坐标系恢复”，本补丁不猜测两套世界的对齐；不会自动清模型后假装继续扫描。要实现这种情况下的自动续扫，需要在当前会话模型上建立可靠 PnP/地图匹配及尺度一致性验证，超出这次已验证修改。

本补丁未新增 ICP、回环优化或全局位姿图，也不能消除单目深度模型的所有跨视角形状误差。弱纹理、反光、透明、运动物体、快速大幅转动仍可能暂停融合。保留旧结果与停止错误追加优先于展示不可信的新点。

手动关闭深度标定的旧 native 调试入口仍保留，常规 UI 路径应维持标定开启；本次删除的是自动超时绕过。

- `python3 tools/review_tests/run_continuity.py`：通过。执行实际生产预测函数，覆盖匀速平移/旋转、非整采样时刻插值、IMU 偏置、缺失/间断数据、旧时间与超时拒绝、相机非单位外参、AR 位姿插值及空洞拒绝。

- `python3 tools/review_tests/run_geometry.py`：通过。投影、固定逆深度标定、无效值、世界坐标、体素预算与平面网格。
- `python3 tools/review_tests/run_scan_policy.py`：通过。扫描径向范围、尺度单位、冻结映射证据、近距离 TSDF 网格。
- `python3 tools/review_tests/run.py`：通过。普通/纹理 GLB、非法网格、坐标手性与 AR 资产保存读取。
