# MobileScan3D vc183 大版本 Master Plan

## 1. 大版本定位

vc183 的目标不是继续增加更多“专家参数”，而是把现有 3D 扫描能力包装成一套真正面向消费者的完整工作流：

```text
锁定物体
→ 跟随方向扫描
→ 自动判断缺失
→ 回到缺失方向补扫
→ 自动清理模型
→ 保存为项目
→ 测量 / AR / 导出 / 分享
```

vc183 完成后，产品需要从“可以扫描”提升为：

> 普通用户第一次使用时，也能在较少学习成本下稳定生成一个完整、干净、可使用的 3D 模型。

## 2. 六阶段统一规划

### vc183.1 — Guided Scan
核心：
- 标准扫描模式
- 动态方向箭头
- 轨迹环
- 距离提示
- 运动质量提示
- 顶部/下半部引导
- 下一最佳视角基础版
- 完成判断

目标：
降低第一次扫描失败率。

### vc183.2 — Scan Recovery Loop
核心：
- 缺口方向识别
- 3D 查看缺失高亮
- “继续补扫”
- 从 3D Review 返回扫描
- 自动定位缺失方向
- 补扫完成后回到 Review

目标：
形成真正的扫描质量闭环。

### vc183.3 — Model Cleanup
核心：
- 去浮点
- 去孤岛
- 去桌面/底座
- 小孔修复
- 法线修复
- 网格简化
- 纹理清理
- 一键优化

目标：
把“算法原始模型”变成“消费者愿意保存和分享的模型”。

### vc183.4 — Project Library
核心：
- 我的模型
- 项目缩略图
- 名称/日期/大小/质量
- 继续处理
- 继续补扫
- 导出
- 删除
- checkpoint 恢复
- 异常退出恢复

目标：
把一次性扫描工具升级为长期可使用的产品。

### vc183.5 — Adaptive Scan
核心：
- 自动估算物体尺度
- 自动推荐距离
- 自动选择扫描策略
- 光照风险
- 反光/透明风险
- 背景相似度风险
- 运动速度自适应
- 性能/热状态自适应

目标：
减少用户设置，让系统自己决定更多。

### vc183.6 — Measure & Share
核心：
- 包围盒尺寸
- 高/宽/深
- 两点距离
- AR 摆放
- 多格式导出
- 分享模型
- 文件大小/精度预设

目标：
让模型“生成以后有实际用途”。

## 3. 产品原则

### 3.1 默认自动，而不是默认复杂
普通用户默认只需要：
- 对准物体
- 开始扫描
- 跟随提示
- 完成模型

### 3.2 技术指标转成动作
不要让用户理解：
- VIO
- TSDF
- depth valid ratio
- viewpoint bins

而要显示：
- `向右移动`
- `稍微后退`
- `顶部还缺一些`
- `扫描完整，可以生成`

### 3.3 高级能力不等于主界面堆按钮
主界面只保留高频操作：
- 物体追踪
- 补光
- 预览
- 开始/暂停
- 模型

高级参数放设置或自动映射。

### 3.4 失败必须可恢复
消费级必须假设：
- 用户会接电话
- 会切后台
- 会误触返回
- 会锁屏
- 会遇到过热
- 会遇到低存储

任何 5–10 分钟扫描都不应因为一次中断全部丢失。

---

## 4. 统一用户旅程

### 第一次使用
1. 简短权限解释
2. 3 屏以内标准扫描教学
3. 进入扫描

### 扫描前
1. 自动寻找目标
2. 自动估计目标尺度
3. 自动判断距离
4. 提醒材质/光照风险
5. 追踪稳定后允许开始

### 扫描中
1. 水平环绕
2. 顶部
3. 下半部
4. 缺失方向
5. 运动过快/抖动提醒
6. 自动判断完成

### 扫描后
1. 3D Review
2. 缺口高亮
3. 继续补扫 or 生成
4. 自动清理
5. 保存项目

### 模型使用
1. 查看
2. 测量
3. AR
4. 导出
5. 分享

---

## 5. vc183 最终 Definition of Done

只有满足以下条件，vc183 才算完整：

- 新用户可在无人工说明下完成扫描
- 标准模式可给出实时方向指引
- 缺口可定向补扫
- 扫描中断可恢复
- 模型生成后可一键清理
- 模型自动进入项目库
- 项目可以重新打开
- 基础尺寸可测量
- GLB/OBJ/PLY 至少三种导出可用
- 3D 查看页可正常退出
- 10 分钟扫描不崩溃、不持续泄漏
- 中高端 Android 设备体验稳定
