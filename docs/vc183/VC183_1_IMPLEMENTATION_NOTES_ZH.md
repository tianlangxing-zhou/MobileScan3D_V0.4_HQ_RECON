# vc183.1 Guided Scan 实现说明

本增量是 vc183 大版本的第一轮真实源码实现，不是规划文档。

## 已实现

- 新增纯 Kotlin `ScanGuidanceController`，读取现有追踪、VINS、距离、角速度和 12+2 视角覆盖状态。
- 新增 `ScanGuidanceOverlay`：在物体外围显示轻量环绕轨迹、当前位姿点、下一推荐方向箭头和上下补扫箭头。
- 新增 4 步标准扫描状态：`锁定物体 → 环绕扫描 → 上下补扫 → 补齐缺口`。
- 标准模式默认开启；更多菜单可在“标准引导 / 自由扫描”之间切换。
- 标准模式开始扫描时自动开启物体追踪能力；若尚未选目标，会先提示点选/拖框。
- 追踪丢失、距离异常、运动过快优先于方向提示。
- 增加“原地只旋转手机”启发式提示：角速度较高但相机仍停留在同一环绕扇区时，提示围绕物体移动。
- 顶部补扫和下半部补扫已接入；桌面接触底面不作为完成硬门槛。
- 扫描满足基础覆盖/采集/几何条件后提示“扫描信息已经足够，可以完成并检查模型”。
- 自由扫描模式继续复用 vc182 的原有覆盖提示，不改变原重建逻辑。

## 本轮明确没有改

- TSDF 融合数学
- VINS 求解
- 深度模型
- 网格生成
- 纹理生成

引导模块只解释已有状态，因此关闭“标准引导”后应基本保持 vc182 扫描行为。
