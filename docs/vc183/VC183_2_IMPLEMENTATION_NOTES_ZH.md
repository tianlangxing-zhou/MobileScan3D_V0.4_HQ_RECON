# vc183.2 Scan Recovery Loop 实现说明

本轮基于 vc183.1 标准扫描引导继续实现“检查 → 定向补扫 → 自动复查”闭环。

## 已实现

- 新增 `ScanRecoveryPlanner`，根据现有 12+2 视角覆盖、采集充分度、表面覆盖和几何质量生成最多 3 个补扫目标。
- 同一片连续侧面缺失不会机械占满全部目标：相邻弱扇区会做简单抑制，优先选择更分散的短板。
- 扫描检查页继续使用真实 TSDF observation weight 热力：红/黄表示真实低观测表面。
- 检查页新增更明确的“优先补扫”摘要，例如：`右后侧 · 顶部`。
- “继续补扫”会把计划写入 `ScanGuidanceController`，回到相机后轨迹环直接指向第一个缺失方向。
- 侧面补扫使用方向箭头；顶部/下半部补扫使用上下箭头。
- 每个目标达到更高覆盖阈值后自动推进下一个目标。
- 本轮目标全部满足后，保持约 1.6 秒稳定并至少补扫 3.5 秒，自动重新进入扫描检查页。
- 自动定向补扫最多建议 3 轮，之后仍允许“自由补扫”或直接生成，避免无限循环。
- 桌面接触底面仍不作为强制完成条件。

## 没有伪造的能力

- Review 热力来自已有真实 TSDF 表面观测权重。
- “方向缺口”来自已有相机视角覆盖，不声称等同于精确 mesh 孔洞定位。
- 本轮没有改 TSDF、VINS、深度模型或网格生成数学。
