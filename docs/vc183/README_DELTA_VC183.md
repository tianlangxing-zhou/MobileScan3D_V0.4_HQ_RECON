# MobileScan3D vc183 标准扫描引导规划增量包

**适用基线**：vc182 / `0.14.2-consumer-ux2`  
**本增量包类型**：规划与规格文档增量，不包含完整工程，不覆盖 vc182 已有源码。  
**建议下一版本号**：vc183 / `0.15.0-guided-scan`

本增量包用于把“消费级标准扫描引导”正式纳入下一版开发。它不重复打包上一轮完整源码，只包含新增的产品规格、研发规划、验收标准和机器可读清单。

## 结论

建议加入“标准扫描引导”，并将其作为消费级版本默认扫描模式。

关键不是播放一套固定教程，而是建立**实时、自适应的下一视角引导（Next Best View Guidance）**：

- 用户先锁定物体；
- 系统根据目标追踪、VIO 位姿、深度有效率、视角覆盖、TSDF 表面观测质量判断“下一步最值得补扫的位置”；
- 界面只给一个当前最重要的动作；
- 已充分扫描的方向自动淡出；
- 缺失方向以轻量轨迹环、箭头和简短文案提示；
- 达到质量阈值后主动提示“可以生成模型”，而不是让用户无限继续扫描。

## 建议的两种模式

### 标准扫描（默认）
面向普通消费者：

- 目标锁定
- 距离提示
- 水平环绕
- 顶部补扫
- 下半部补扫
- 缺口定向补扫
- 完成判断
- 质量复核

### 自由扫描
面向熟练用户：

- 不显示强流程步骤
- 保留追踪状态
- 保留质量/覆盖提示
- 仅在明显缺失或追踪异常时提示
