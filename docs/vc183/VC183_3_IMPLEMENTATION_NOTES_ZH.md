# vc183.3 Model Cleanup 实现说明

## 目标

把原本只在“纹理 GLB 导出副本”中运行的几何后处理能力，升级为消费者在 3D 查看页可以直接使用的一键模型优化，同时保证原始模型可撤销恢复。

## 已实现

### 一键优化
3D 查看页右侧新增一级“优化”按钮。

默认执行“标准”档：
1. 亚毫米级顶点焊接；
2. 去小连通分量 / 漂浮孤岛；
3. 小孔修复（只补尺寸受控的小边界环）；
4. 保守的桌面/支撑平面清理；
5. QEM 网格简化；
6. 顶点压缩和法线重算。

### 去桌面策略
工程的 VINS 世界坐标已约定物理向上为 world +Z。

桌面清理不是“删最低平面”这种高风险方案，而是：
- 只分析模型底部区域的近水平三角面；
- 从更高处几何估算主体 XY footprint；
- 只删除支撑平面中主体 footprint 外侧的部分；
- 如果候选平面没有明显超出主体 footprint，则不删除；
- 如果预计删除比例过高，则安全拒绝。

因此宁可留下少量桌面，也不自动切掉花瓶/盒子的真实平底。

### 安全回退与撤销
- 优化在网格副本上完成；
- 所有步骤成功并通过“剩余几何比例”安全门后，才替换查看模型；
- native 保留完整的优化前网格；
- 优化后按钮变为“撤销”，可以恢复精确的优化前网格；
- 任何失败不会修改当前模型；
- 硬表面拟合（平面/立方体等）自动跳过，避免破坏独立硬边。

### 导出一致性
vc182/vc183.2 的普通 GLB 导出会重新从 TSDF 构建网格，这会覆盖用户刚做的一键优化。

vc183.3 已修改：
- 当前网格处于 optimized 状态且不是硬表面 shape 导出时，不再重建；
- 直接使用用户看到的优化后网格做纹理烘焙和 GLB 导出；
- 已优化网格在纹理导出时不会再次执行 QEM/去分量，避免二次过度简化；
- 拓扑改变后旧 textured AR asset 会清空，下一次导出重新烘焙。

## 优化统计

Native 提供 18 槽统计，包括：
- 输入/输出顶点、三角面；
- weld 顶点数；
- 去除孤岛及三角面数；
- 边界环和补孔数量；
- QEM collapsed edges；
- 是否检测到桌面/支撑平面及移除面数；
- profile；
- undo 是否可用；
- optimized 状态；
- 状态码；
- 耗时。

## 本轮没有修改

- TSDF 融合
- VINS
- 深度网络
- 扫描 Guidance
- 补扫规划

优化仅修改当前 viewer/export mesh，原 TSDF 保持完整。
