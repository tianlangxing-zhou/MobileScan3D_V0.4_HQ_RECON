# MobileScan3D vc183 验收标准
目标版本：0.15.0-guided-scan

## 1. 功能验收

### 1.1 目标锁定

- [ ] 物体完整入框后可进入追踪
- [ ] 追踪状态在一级 UI 可见
- [ ] 追踪丢失有明显但不过度打扰的提示
- [ ] 恢复目标后可继续原扫描流程

### 1.2 水平环绕

- [ ] 可以识别当前相机相对目标的方位角变化
- [ ] 水平覆盖至少 12 个方向桶
- [ ] 已完成方向不重复强提示
- [ ] 推荐方向 0.8 秒内不抖动切换
- [ ] 用户反向移动时仍能正确累计有效扫描贡献

### 1.3 顶部/下部

- [ ] 水平覆盖足够后可进入顶部提示
- [ ] 顶部已经充分时自动跳过
- [ ] 桌面接触底面不会被当作必扫区域
- [ ] 下半部可见区域不足时可提示补扫

### 1.4 缺口恢复

- [ ] 可把明显缺失映射到大致方向
- [ ] 同一时间只显示一个主要补扫方向
- [ ] 扫描补齐后提示自动消失
- [ ] 缺口消失后完成度提升

### 1.5 完成判断

- [ ] 不只依赖单一百分比
- [ ] 可输出“建议继续”与“可以生成”
- [ ] 完成后仍允许用户继续扫描
- [ ] 完成后主 CTA 可变为“完成扫描/生成模型”

---

## 2. UX 验收

- [ ] 新用户不阅读文档也能完成一次标准扫描
- [ ] 主界面不新增超过 1 个永久信息块
- [ ] 箭头不遮挡主体
- [ ] 指引文案 <= 18 个中文字符为主
- [ ] 红色只用于错误/高风险
- [ ] 方向提示不会一秒内多次反转
- [ ] 用户不需要理解“TSDF”“VIO”等术语

---

## 3. 性能验收

- [ ] Guidance UI 不引起明显卡顿
- [ ] 长扫描无持续内存增长
- [ ] Guidance Controller 平均计算时间 <= 3ms
- [ ] 覆盖/NBV 更新频率可控制在 5–10Hz
- [ ] 热状态下 Guidance 能降频而不影响核心扫描

---

## 4. 稳定性验收

- [ ] 追踪丢失再恢复
- [ ] App 切后台再回来
- [ ] 锁屏再解锁
- [ ] Camera 重启
- [ ] 低内存
- [ ] 低存储
- [ ] 热降频
- [ ] 用户中途退出扫描

以上场景不得造成 Guidance 状态错乱或崩溃。

---

## 5. 模型质量验收

建议建立固定测试物：

1. 白色哑光杯
2. 蓝白纹理花瓶
3. 深色塑料玩具
4. 带凹槽的小雕塑
5. 有遮挡的桌面摆件

比较 vc182 vs vc183：

- [ ] 模型完整度不下降
- [ ] 背面缺失率下降
- [ ] 顶部缺失率下降
- [ ] 平均有效扫描完成率上升
- [ ] 首次成功率上升
- [ ] 平均重扫次数下降

---

## 6. 设备矩阵

至少：

- [ ] Snapdragon 旗舰
- [ ] Dimensity 旗舰
- [ ] 中端 Android 设备
- [ ] 无 ToF / LiDAR 设备
- [ ] 不同 Camera2 HAL 厂商

---

## 7. 用户测试建议

找 10–20 名没有 3D 扫描经验的用户。

任务：

> 不提供人工指导，扫描一个桌面花瓶并生成模型。

记录：

- 是否完成
- 扫描时间
- 用户停顿位置
- 是否误解“旋转”
- 是否漏顶部
- 是否漏背面
- 是否主动看帮助
- 是否理解“可以生成”

最重要问题：

> “下一步该怎么动，你能不能一眼看懂？”

如果这个问题不能稳定回答“能”，vc183 还不应结束。
