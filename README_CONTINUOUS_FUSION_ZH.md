## 覆盖与构建

1. 先备份本地工程，尤其是尚未提交的修改。本包按上述提交制作；本地有额外改动时先比较文件。
2. 解压 ZIP，将其中的 `app/`、`tools/`、`docs/` 等内容复制到工程根目录，选择合并文件夹并覆盖同名文件。工程根目录就是包含 `settings.gradle.kts` 的目录，不要再嵌套一层文件夹。
3. 本包是**改动文件覆盖包**，不是独立完整工程，也不是 APK。保留本机 `local.properties`、SDK/NDK/Ceres 路径、签名和其他未修改文件；不需要另外应用旧的 patch 文件。
4. Android Studio 同步后执行 Clean/Rebuild；Windows 可执行 `gradlew.bat :app:assembleDebug`，macOS/Linux 可执行 `./gradlew :app:assembleDebug`。
5. 安装新的 debug APK，版本应显示 `0.13.19-continuous-fusion`。开始一次新的扫描，旧扫描里已经出现的重影不会被此补丁自动修好。

## 使用与验收

- 固定被拍摄物体，只移动手机。先缓慢平移建立 VINS 定位和深度标定，再锁定一次目标，保持相邻视角有重叠。
- 用默认“实时”图层观察：现在只显示世界坐标累计点云和网格。单帧亮绿色点仍可在调试图层查看，不属于已融合模型。
- 从正面缓慢移到侧面再回到正面：先前扫描的表面应保留，新表面应在同一物体上追加，不应按视角清空重建。
- 遮挡/快速移动造成不可靠定位时，新融合会暂停，已有模型保留。恢复可靠定位后继续；如果 VINS 内部已经重启世界坐标，先停止并导出，再重新开始扫描。此包不实现跨世界坐标的自动重定位续扫。
- 不要在绕物体移动时反复点击重新选目标：现有产品语义仍然是“重新选目标 = 新目标模型”。
- 停止后检查模型查看器和导出的 GLB，而不只看绿色调试点。
