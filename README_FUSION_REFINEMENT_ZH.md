# vc155 运行效率与融合精度增量替换包

适用基线：本次上传的 `MobileScan3D_core_src_vc155_round234_20261001.zip`。
GitHub 链接在本次环境中无法读取，因此没有核对线上 HEAD，也没有修改远程仓库。
本包仅包含相对附件新增或修改的工程文件，不是完整工程，也不含 APK。

## 替换方法

1. 备份本地工程。先在解压的补丁目录执行：
   `python3 MobileScan3D/tools/review_tests/verify_fusion_refinement_overlay.py --before <原工程根目录>`。
   原工程根目录应包含 `app/`。校验不通过说明版本或本地改动不同，请先按差异合并。
2. 将 ZIP 中 `MobileScan3D/` 内的内容按目录合并覆盖到工程根目录，不要删除原工程其他文件。
3. 在覆盖后的工程根目录执行：
   `python3 tools/review_tests/verify_fusion_refinement_overlay.py`。
4. 使用原工程已配置好的 Android SDK、NDK、Ceres、OpenCV 环境重新编译。
   `surfel_engine.h` 的内部结构有变化，必须重新编译原生库，不能混用旧二进制。

## 修改内容

- `tsdf_engine.cpp`：保留单块快速路径，增加 64 项栈上块缓存，降低相邻射线重复进入同一块时的哈希表访问。缓存仅在一次融合调用内存在，完整比较块坐标，保留容量不足的空结果；不改采样顺序、TSDF 数值公式、权重和颜色更新。
- `surfel_engine.cpp/.h`：固定比例更新改为累计置信权重融合，历史权重上限 32；位置采用双精度中间计算，RGB 使用浮点累积后四舍五入输出，避免逐次截断导致小颜色变化永久无法收敛。压缩和重新激活同步维护累积状态。
- 预览 hits≥2/3 的计数增量维护，常用 HUD 查询从遍历全部点改为常数时间；压缩、删除、重建索引和 reset 均同步计数。
- 预览采用整数均匀抽样，实际输出 `min(符合阈值的点数, 预算)`，避免超过预算一点就减半的现象；仍保留 minHits 过滤。
- `depth_calib.cpp`：标定使用精确预算的均匀抽样，避免 513 个输入、512 上限时仅采 257 个；使用商余数递推，不引入大整数乘法溢出。

## 验证结果

在当前 Linux 主机使用 g++ / C++20 验证，非 Android 真机测量。

| 项目 | 上传基线 | 修改后 |
|---|---:|---:|
| 固定随机种子、静止点均匀深度噪声的 RMS | 0.767179 mm | 0.200521 mm |
| RGB 红通道从 101 变为 102，多次观测后的值 | 101 | 102 |
| 1001 个有效点、1000 点显示预算 | 501 点 | 1000 点 |
| 513 个标定输入、512 上限 | 257 个样本 | 512 个样本 |
| 777 个标定输入、512 上限 | 389 个样本 | 512 个样本 |
| 1025 个标定输入、512 上限 | 342 个样本 | 512 个样本 |
| 10 万点、2000 次双阈值计数查询（三次中位数） | 313.214 ms | 0.010065 ms |
| TSDF 融合基准内部中位耗时（一次 A/B） | 4.84974 ms/帧 | 4.67070 ms/帧 |

TSDF 主机基准本次耗时降低 3.69%，两边摘要均为 `10245960488155071710`，体素数 29432、块数 128，测试覆盖的 TSDF 值、权重和颜色完全一致。这个小幅性能变化受主机调度影响，不应直接换算为手机帧率。

以下最终测试均通过，原生正确性测试启用 AddressSanitizer / UndefinedBehaviorSanitizer（当前受限主机禁用 LeakSanitizer）：

```sh
python3 tools/review_tests/run_fusion_refinement.py --baseline <上传基线解压目录>
python3 tools/review_tests/run_optimization.py --baseline <上传基线解压目录>
python3 tools/review_tests/run_round4.py
python3 tools/review_tests/run_geometry.py
```

包括颜色收敛、置信权重、静止噪声、真实变化跟随、采样预算边界、重置、压缩与重新激活、深度标定、负坐标、TSDF 容量、移动斜面、细结构保护、网格保留。移动含噪斜面网格最大误差约 1.304 mm；静态对照场景的稠密/自适应网格均为 58371 个三角形。这些是限定合成场景结果。

## 成本与验证边界

- 每个 Surfel 多 16 字节。60 万点时有效数据约多 9.2 MiB，vector 预留容量还可能增加实际占用；换取颜色的小数精度与历史置信权重。共面压缩场景仍从 1600 点降至 400 点。
- 权重上限 32 会降低静止噪声，但对连续变化的响应比旧版更慢。矛盾细节重新激活时重置历史权重；新增测试验证持续新观测最终能收敛。
- 预览填满预算会比旧版欠采样输出更多点，GPU 绘制成本可能相应增加，但不会超过调用方预算。
- 标定在某些输入规模上使用更多有效候选样本，计算量可能增加，但不超过原配置 maxSamples。
- 噪声 RMS 改善针对预览 Surfel；最终 TSDF 网格算法未变，不宣称真实扫描的绝对尺寸精度提升相同比例。
- 尚未完成 Android 全工程编译、手机扫描、长时间温控和真实照片烘焙验证。当前附件/环境没有完整可用的 Android 外部依赖构建配置。
